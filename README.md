# VM-XCtrl

### Turn your Behringer X-Touch into a powerful VoiceMeeter mixer, Windows application mixer, and intelligent media controller.

VM-XCtrl is a native Windows application that deeply integrates **Behringer X-Touch** with **VB-Audio VoiceMeeter Potato**, transforming the controller into a complete hardware mixing console for VoiceMeeter, Windows applications, and media playback.

Unlike generic MIDI mappings, VM-XCtrl provides full two-way communication with motorized faders, scribble strips, LEDs, peak meters, routing control, intelligent media integration, and automatic synchronization.

Built on a modern native C++ architecture, VM-XCtrl delivers excellent performance, reliability, and a seamless user experience.

# Overview

VM-XCtrl extends the Behringer X-Touch far beyond traditional mixer control.

It combines four powerful workflows into a single hardware surface:

- 🎚 VoiceMeeter Mixing
- 🖥 Windows Application Mixer
- 🎬 Intelligent Media Controller
- 🔀 Hardware Audio Routing

Every hardware control—including motorized faders, encoders, buttons, displays, LEDs, and peak meters—remains synchronized with VoiceMeeter in real time.

Whether you're streaming, gaming, recording, or simply managing desktop audio, VM-XCtrl lets you work directly from the hardware without constantly switching back to the VoiceMeeter interface or Windows Volume Mixer.

# Features

## 🎚 VoiceMeeter Mixing

Complete hardware control over VoiceMeeter.

### Inputs & Outputs

- Dedicated **Input** layer
- Dedicated **Output** layer
- Dedicated **SEND (AUX)** layer
- Global View routing overview
- Output selection indicators
- Extra VAIO Routing control
- Main Fader assignment to any output bus
- Optional Main Fader control while on Output and SEND layers
- Preset recall using **F1–F8**

### Faders

- Motorized faders
- Touch-sensitive faders
- Relative & Absolute slider modes
- Live gain value display while touching faders

### Monitoring

- Real-time Peak Meter Bridge
- Configurable meter refresh rate
  - 50 ms
  - 100 ms
  - 200 ms
- Configurable clipping indicator
- Full VoiceMeeter state synchronization

---

## 🖥 Windows Application Mixer

The **APPS Layer** transforms your X-Touch into a dedicated Windows application mixer.

Control individual application volumes, mute applications, browse running software, and change playback devices—all directly from the hardware.

No Windows Volume Mixer required.

### Features

- Per-application volume control
- Per-application mute
- Supports unlimited running applications
- Browse applications 8 at a time
- Dedicated Windows Default Output slot
- Real-time motorized fader feedback
- Dynamic scribble strip labels
- Scroll long application names
- Scroll long playback device names

### Audio Routing

Instantly move any running application between:

- VoiceMeeter VAIO
- VoiceMeeter AUX
- VoiceMeeter VAIO3
- Extension buses
- Physical playback devices
- Virtual audio devices

Routing changes are performed directly from the encoder section using **Global View**, without opening Windows Sound Settings or VoiceMeeter.

### Smart Display

Applications and playback devices are color-coded for quick identification.

- 🟨 VoiceMeeter buses
- 🩷 Extension buses
- 🟦 External playback devices

VB-Audio virtual devices automatically display short product names instead of generic labels for improved readability.

---

## 🎬 Intelligent Media Controls

VM-XCtrl includes an advanced media control system designed specifically for modern Windows applications.

Unlike standard multimedia keys, media commands always target the active media session instead of random background applications.

### Features

- Focus-aware media targeting
- Windows SMTC integration
- Browser video support (YouTube, Twitch, etc.)
- Intelligent seek fallback
- High-precision Jog Wheel scrubbing

### Controller Modes

#### XCtrl

- Transport buttons control media playback
- Jog Wheel controls media seeking

#### XCtrl Mackie

- Media controls are mapped to the Automation section

## ⚙ Smart Automation

VM-XCtrl minimizes setup and maintenance by handling most tasks automatically.

### Automatic VoiceMeeter Detection

The application automatically locates the VoiceMeeter installation and loads the required API libraries.

Compatible with:

- VoiceMeeter Potato 3.1.1.9+
- VoiceMeeter Banana 2.1.1.9+
- Future VoiceMeeter releases

Older versions may also work but have not been officially tested.

If VoiceMeeter cannot be detected automatically, VM-XCtrl will ask you to select the installation folder manually.

The configured location can be changed later from the tray icon menu.

### Automatic Updates

- Automatic update checks on startup
- Manual update check
- Skip selected releases
- Built-in release notes

### Startup

- Native **Start with Windows**
- Enabled by default
- No Task Scheduler or additional scripts required

# Getting Started

1. Install VoiceMeeter Potato or Banana.
2. Install VM-XCtrl.
3. Launch the application.
4. VM-XCtrl will automatically detect your VoiceMeeter installation.
5. Configure your X-Touch in **XCtrl**, **XCtrl Mackie**, or **XCtrl HUI** mode.
6. Enter your computer's IP address on the X-Touch.
7. VM-XCtrl will automatically connect and synchronize the entire control surface.
